# 주간 운영 대시보드

`BIODANCE_BI_Ops_Dashboard.xlsx` · Excel과 Google Sheets 공통 함수만 씁니다 (COUNTIFS, SUMIFS, AVERAGEIFS, SUMPRODUCT, INDEX/MATCH, CRITBINOM). Google Drive에 올려 Google Sheets로 저장하면 그대로 동작합니다.

## 탭

| 탭 | 역할 |
|---|---|
| 0_가이드 | 목적 · 월요일 루틴 · 입력 예시 |
| 1_대시보드 | 수식만 (입력 금지). A 시장 신호 · 리뷰 경고 · 결정 기록 요약 |
| 2_설정 | ASIN · 정가 · 기준 주 · 경고 기준 |
| 3_시장신호 | 일별 BSR · 가격 · 평점 · 누적 리뷰 (ASIN별 한 줄) |
| 4_트렌드 | Google Trends 일별 지수 (추출 ID별) |
| 5_리뷰모니터링 | 지난주 1–2점 리뷰와 분류 (운영 시작 후 입력) |
| 6_진단테스트 · 7_내부데이터 | 테스트 기록 · CS·반품 등 내부 숫자 (입사 후 입력) |
| 8_지표정의 | 지표마다 정의와 분모 |
| 9_분석동결 | 보고서에 쓴 고정 수치 (수정 금지) |
| 10_출처검증 | 숫자별 원본 · 검증 수준 · 표현 제한 |
| 11_카탈로그 | 월 1회 제품 목록 · 형태별 자동 집계 |

## 월요일 루틴

1. 3_시장신호에 지난주 일별 순위·가격·리뷰 수를 추가합니다.
2. 4_트렌드에 같은 검색어 묶음의 지수를 새 추출 ID로 추가합니다.
3. 5_리뷰모니터링에 지난주 1–2점 리뷰를 추가하고 분류합니다.
4. 1_대시보드에서 경고를 확인하고, 결정과 근거를 6_진단테스트 결정 기록에 남깁니다.

## 리뷰 경고 기준

최근 4주 1–2점 리뷰 n건 중 특정 불만 언급 수가 `CRITBINOM(n, 기준선, 0.975)`를 넘으면 경고합니다. 기준선이 맞다면 2.5% 이하로만 나올 수치입니다. 최근 4주 1–2점이 30건보다 적으면 표본 부족으로 판정을 보류합니다.

## 같은 조건 비교

1_대시보드의 "7일 평균 BSR"은 100위 안에 든 날만의 평균입니다. 든 날 수가 다르면 같은 조건 비교가 아니므로, "최근 7일 100위 안 일수 / 기록일"을 같이 봅니다.
