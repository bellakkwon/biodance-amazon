# 바이오던스 미국 Amazon 공개 데이터 분석

미국 Amazon에 공개된 순위·가격·구매 배지·리뷰로 바이오던스가 마스크 다음으로 키울 제품을 찾고, 내부 데이터 없이도 바로 해볼 수 있는 일을 제안한 분석입니다. 특정 기업의 내부 데이터는 쓰지 않았습니다.

## 질문

1. 바이오던스는 마스크 다음으로 무엇이 팔리고 있나?
2. 그 제품은 할인 없이도 버티나, 할인 때만 오르나?
3. 브랜드가 바로 고칠 수 있는 것은 무엇인가?

## 결과 요약 (괄호 = 보고서 쪽)

- **공개 구매 배지 기준, 붙이는 제품이 하한 합계의 77%** (00·02). 마스크 145K+, 아이패치 110K+, 넥패치 29K+ / 전체 368.1K+. 구매 배지는 Amazon이 보여 주는 "지난달 구매" 하한이라 실제 판매 구성비가 아닙니다.
- **아이패치는 정가 기간에도 순위를 지켰다** (03). 리뷰에서 사용 빈도를 적은 13건 중 8건이 매일 쓴다고 했습니다(별점별 표본). 11/1–19 정가일 Skin Care 순위 중앙값 바이오던스 26위, 메디큐브 70.5위. 블랙프라이데이 할인일(11/23)에는 12위 vs 11위로 비슷합니다. 10월 할인(10/7–8) 뒤 정가로 12일간 BPC 18–24위를 유지했다가 10/29에 55위로 돌아왔습니다(1회 사례).
- **상세페이지 문구가 고객이 쓰는 방식과 어긋난다** (00·04).
  - 같은 페이지 안에서 마스크 비교 이미지의 ‘#15-min Magic’과 How to Use의 ‘20–30분’이 다릅니다. 리뷰에 적힌 착용 시간도 15분 기준 4건, 20–30분 5건으로 나뉩니다.
  - ‘Makeup-Ready Skin’을 내세우지만, 미국 리뷰 385건 중 화장을 언급한 11건에 5점이 없고 화장 밀림이 7건입니다.
- **제안** (04·05). 사용 시간 표기는 제품팀 확인 후 하나로 맞추고, 화장 전 사용법 한 줄만 A/B로 시험합니다(A안 = 지금 페이지, B안 = 지금 페이지 + 사용법 한 줄, 판단 지표 = 방문자당 구매). 판매가 1% 늘면 월 약 800개(구매 배지 하한 8만+ 기준)입니다. 불만 건수가 가장 많아서가 아니라, 제품을 바꾸지 않고 콘텐츠만으로 싸게 시험하고 되돌릴 수 있어서 먼저 고릅니다. 건수가 더 많은 ‘효과 체감 없음’(93건)은 제품·기대치 문제라 CS·반품 데이터로 먼저 확인합니다.

| 데이터 | 출처 | 기간 | 해석 제한 |
|---|---|---|---|
| 카테고리 상위 50 (마스크·아이·세럼) | Amazon Best Sellers 화면 | 2026-11-23 하루 | 블랙프라이데이 주간 · 리스팅 기준 |

| 아이패치 리뷰 385건 | Amazon 리뷰 (미국) | ~2026-11-23 | 별점별 표본이라 건수만 사용 |

파일별 열 설명과 수집 방법은 [`data/README.md`](data/README.md)에 있습니다.

## 다시 계산하기

```bash
pip install -r requirements.txt
python analysis/run_all.py
```

보고서에 쓴 숫자 33개를 `data/`에서 다시 계산하고 보고서 값과 비교해 [`outputs/numbers.md`](outputs/numbers.md)에 적습니다. 하나라도 다르면 실패로 끝납니다.

## 한계

- 구매 배지는 하한이고, 순위는 판매량이 아닙니다. 둘 다 내부 매출을 대신하지 않습니다.
- 순위·가격은 56일, 상위 50은 하루 자료입니다. 같은 기간의 광고·쿠폰은 확인하지 못했습니다.
- 리뷰는 최신순 100건 + 별점별 최신순 100건이라 저평점이 실제보다 많습니다. 비율이 아니라 건수로만 썼습니다.

## 입사 후 내부 데이터로 먼저 확인할 것 (보고서 05)

동시 구매(Market Basket) · 실제 출시일 · PDRN 아이패치 변형 구조 · 검색어별 유입 · CS·반품 사유 · 광고·쿠폰. 결과에 따라 04의 우선순위가 바뀝니다.

## 올리지 않은 것

리뷰 원문과 작성자 이름, Amazon 상세페이지 캡처, Spate 보고서 원본, Keepa·ParseShelf 원본 화면은 올리지 않았습니다. 리뷰 분류 기준은 `tools/code_eye_reviews.py`에 있습니다.
